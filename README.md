# StudentAnalysis

The Student Performance Analysis System is a mini project developed using Python and Data Science concepts to analyze and predict student academic performance. The project studies factors such as study hours, attendance, sleep hours, and marks obtained by students. It also visualizes relationships between these factors using graphs and predicts marks using a Linear Regression model.

## Features
- Statistical analysis of marks
- Scatter plot visualization
- Correlation heatmap
- Bar chart representation
- Student grade classification
- Linear Regression prediction model

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
